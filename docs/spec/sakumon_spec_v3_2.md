# 作問支援 仕様 v3.2 追補（2026-09-18）— 文言を「求めるもの」軸に統一

v3.1（`sakumon_spec_v3_1.md`）の 3-3（称賛）・3-4（弱）・3-5（中）・3-6（強）・3-7（完了）・5（対話の境界）の文言と規則を置き換える。
4段階（どこまで示すか）・3カウンタ・強度の遷移・宣言の扱い（1回で閉じる）は v3.1 のまま。

## 1. 経緯（9/18 模擬実践 #04）

- 称賛「4が ちがう ものの 数に なる お話は 作れるかな？」を、児童は「ちがう もの＝題材の変更」と読んだ（おにぎり→ビー玉→クッキー。4は「4こずつ」のまま）。
- 児童が「4が違うものの数になるってどういうことですか？」と尋ねても、強度0では除数の役割を言えないので説明できなかった。
- 「わかんない」「どういうことですか？」の2ターンで弱→強に飛び、児童は中を一度も試せなかった。
- help で中に上がったターンで、旧強度の talk が「くらべる ような 使い方」と示唆した直後に中の定型が「分ける 人の 数に」と指定し、矛盾した。
- 強度2の talk が次の問題の問いの文（「1人分は 何こに なるか、という お話だよ」）まで言い、強の「求める文を書かせる」を無効にした。

## 2. 方針

児童に持たせる枠は **「求めるもの」＝問いの文で答えること**（何人か／1人分が何こか／何倍か）。児童が問題文の最後に直接見えるもので、意味を聞かれても児童自身の問いの文を指して説明できる。
除数の使い方（分ける相手の数／1人分の数／くらべる相手の量）は「求めるものを変えるための手段」で、中（強度2）で初めて目標と結びつけて言う。0・1 では言わない。
これは v3 1章「児童向け語彙は『求める』に統一」と README「選択の基準を指定しない理由」（フェーズ2で「求める」を使い、フェーズ3の選択基準の移動で転移を見る）に沿う。

| 強度 | 示すもの | 誰が目標を決めるか |
|---|---|---|
| 0 促し | 目標の軸だけ（求めるものがちがう お話） | 児童 |
| 1 弱 | 現在地（4の使い方も求めるものも同じ）＋宣言の問い「何を 求める お話に する？」 | 児童（宣言） |
| 2 中 | 目標（何を求めるか）＋手段（4をどう使うか）＋題材固定 | システム |
| 3 強 | 場面文（手段は済ませる）＋求める文だけ書かせる | システム |

## 3. 文言（例は 24÷4・クッキー・こ。`ai_dialogue.py` が正）

**称賛（0）** 児童の問いの文（`question_phrase`。本文末尾の疑問文を正規表現で抽出）を引用：
> 新しい 問題が できたね！ この お話は、『何人に くばれますか』を 求める お話だね。
> 今度は、**求める ものが ちがう** お話は 作れるかな？

同じ構造1回目：「いいね、また 一つ できたね。この お話も、『…』を 求める お話だね。今度は、求める ものが ちがう お話も 作れそうかな？」。問いの文が取れなければ引用の文を落とす。

**弱（1）** 何が同じかを児童の言葉2つ（除数の句＝4の使い方、問いの疑問語＝求めるもの）で言う：

| 変形 | 文言 |
|---|---|
| same | 2ばんの『4こずつ 買います』も 3ばんの『4つ くばると』も、4の 使い方は 同じで、どちらも **何人か**を 求める お話だね。 |
| wakeru | 1ばんは 何人か、2ばんは 何こかを 求めたね。どちらも 24こを 分ける お話だね。じゃあ 次は、24こを 分けない お話に するなら、何を 求める？ |
| kuraberu | 1ばんも 2ばんも、24こと 4こを くらべて、**何倍か**を 求める お話だね。じゃあ 次は、くらべない お話に するなら、何を 求める お話に する？ |
| one | 1ばんは、4を『4こずつ くばります』と 使って、**何人か**を 求める お話だったね。 |

→ 共通の問い「じゃあ 次は、何を 求める お話に する？」。句・疑問語が取れなければその部分を落とす。宣言 unknown・「わからない」→「わからなくても だいじょうぶ。じゃあ、求める ものが ちがう お話を 作って みよう。」

**中（2）**

| 目標 | 文言 |
|---|---|
| 等分除 | 1人分が 何こかを 求める お話に して みよう。4を、分ける 人の 数に するよ。クッキーの お話は そのままで いいよ。 |
| 包含除 | 何人に 分けられるかを 求める お話に して みよう。4を、1人が もらう 数に するよ。クッキーの お話は そのままで いいよ。 |
| 倍 | 24こは 4この 何倍かを 求める お話に して みよう。4を、くらべる 相手の 数に するよ。クッキーの お話は そのままで いいよ。 |

**強（3）**

| 目標 | 文言 |
|---|---|
| 等分除 | 「クッキーが 24こ あります。4人で 同じ 数ずつ 分けます。」つづきの、求める 文を 書いて みよう。 |
| 包含除 | 「クッキーが 24こ あります。1人に 4こずつ 分けます。」つづきの、求める 文を 書いて みよう。 |
| 倍 | 「たろうさんは クッキーを 24こ、お友だちは 4こ もって います。」つづきの、何倍かを 求める 文を 書いて みよう。 |

**上部「つぎは「…」」**（システム指定）：中の目標部分と同じ文「1人分が 何こかを 求める お話」「何人に 分けられるかを 求める お話」「24こは 4この 何倍かを 求める お話」。児童の宣言はその言葉（訂正しない）。

**完了**：各構造に最初に到達した問題の番号と疑問語（到達順）：
> 3つ とも できたね！ 1ばんは『何人か』、3ばんは『何こか』、4ばんは『何倍か』。
> 同じ 24÷4 なのに、求める ものが ぜんぶ ちがう お話に なったね。
> 時間まで、もっと 作って みよう。求める ものが 同じでも、ちがう お話なら いいよ。

疑問語が欠ける・重なるなら「1ばん・3ばん・4ばんは、同じ 24÷4 なのに 求める ものが ぜんぶ ちがう お話だね。」。以降の成立作問は「◯ばんも できたね。この お話は『…』を 求める お話だね。」（促しなし・カウンタ不動）。対話は支援なし。

**「求めるものって何？」**（`asks_what_motomeru`。強度0・1。LLM を呼ばない・help に数えない）：
> 1ばんの お話の 最後の 文、『何人に くばれますか』の ところが『求める もの』だよ。
> 今度は、ここが ちがう お話を 作って みよう。

成立作問が無ければ「『求める もの』は、お話の 最後の 文の ことだよ。「〜は いくつですか」の ところ。」。強度2以上は LLM（行き先を言ってよい）。

## 4. 規則の変更

- **help の連続昇格の抑止**：help で強度を上げたら、児童が作問（不成立でも）か宣言をするまで help ではもう上げない（`database.help_raised_since_last_sakumon`）。help_count は数える。stuck・miss・talk は従来どおり。
- **中・強に上がった help のターン**：talk の文言（旧強度で生成）は捨て、「そっか。じゃあ、こうして みよう。」＋中／強の文言を出す。0→1 は従来どおり talk＋弱を連結。
- **宣言の分類**（`classify_declaration`）：求めるもの型（「何こか」「1人分」→等分除、「何人か」→包含除、「何倍か」→倍）と除数の使い方型（「4人で分ける」→等分除、「4こずつ」→包含除）の両方を受ける。

## 5. 対話（talk）の境界

| 強度 | 言ってよい | 言わない |
|---|---|---|
| 0 | 直前の返事の説明・励まし。「求めるもの」の意味を児童の問いの文を引用して示す | 役割を問う・言う。「分ける／くらべる お話」と分類。何を求めればよいか・4をどう使うか（行き先）。1つ分・いくつ分・何倍・1人分 |
| 1 | 現在地（「2ばんも 3ばんも、4の 使い方は 同じで、どちらも 何人かを 求める お話だね」）。「何を 求める お話に する？」と問い返す。4が何の数か問い返す | 行き先（「何こかを 求める お話に して」「4人で分ける」）。1つ分・いくつ分・何倍・1人分（児童の引用を除く） |
| 2 | 目標＋手段（「1人分が 何こかを 求める お話に して みよう。4を、分ける 人の 数に するよ」）。3語。題材固定 | 場面文。次の問題の問いの文 |
| 3 | 場面文まで | 次の問題の問いの文（「1人分は 何こに なりますか」） |

全強度：答え（商）・構造名・次の問題の問いの文（`question_form`）は禁止。児童自身の問いの文の引用（『…』。言い換えでも疑問語が児童の問いと同じなら）はガードの対象外。禁止語彙（種類・たずねる・聞いていること・ちがうことを聞く）は空白を除いても照合。
違反は理由を添えて1回再生成 → なお違反なら定型「そっか。じゃあ、いま作った 問題とは、求める ものが ちがう お話に して みようか。」

## 6. データ

- `chat_logs.question_phrase`（成立作問の問いの文。正規表現。フェーズ2）。CSV にも出す。
- 宣言の答えは「求めるもの」と「除数の使い方」のどちらの枠で答えたかを本文で分けられる（README 測定指標「宣言の内容の分類」）。

## 7. 児童への事前説明（運用手順 3 章）

フェーズ1の前は操作だけ。「求める もの」の定義（お話の最後で聞いていること）はフェーズ2に切り替えた直後に、今日の式と無関係な例1つで示す。何人／何こ／何倍の3例は挙げない（全員に中を先に与えることになる）。「求めるものがちがう」の意味は説明しない（支援そのもの）。
