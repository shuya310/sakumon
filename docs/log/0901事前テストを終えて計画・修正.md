## 1. 指摘の正体

現在の到達構造数は、**児童が構造を意識した証拠ではなく、我々の分類作業の結果**だ。p.7が等分除2問・包含除2問を書いたとして、本人が「今度は違う型で作ろう」と思ったのか、たまたま浮かんだ場面が異なっただけなのかは、産出物からは区別できない。

9/1のデータには、その区別がつく事例が一つだけある。**p.28**だ。4問で等分除×包含除／1つ分×いくつ分の2×2を構成している。これは偶然では出ない配置で、明らかに意図がある。**32名中1名。**

つまり9/1が示したのは、「作問すれば構造的理解が促される」わけではない、ということだ。平嶋(2005)の「設計としての作問」——ある解法で解ける問題を作るには、その解法が適用できる問題の構成を意識せざるをえない——は、**自由に作らせるだけでは自動的には成立しない**。等分除に偏り（68.5%）、同型反復が多発し（物の名前だけ差し替え）、意図的に作り分けたのは1名。

**これは研究の欠陥ではなく、研究の出発点になる。** 9/1は「作問課題だけでは足りない」ことの実証データだ。何が足りないのか——**自分が今どの構造を作ったかが、本人に返っていないこと**。

## 2. 研究ストーリーの修正

修正前は暗黙にこうなっていた。

> 自由作問 → 多様な構造が産出される → 構造的理解が促される

修正後はこうすべきだ。

> 自由作問だけでは構造は分化しない（9/1で実証）
> → 産出した問題の構造を**その場で本人に返す**
> → 「同じ24÷4でも別の場面がありうる」ことに気づく
> → **意図的に別構造を作りにいく**
> → 構造的理解

変わったのは、**構造的理解の所在が「産出の多様性」から「産出の意図性」に移った**ことだ。何構造書けたかではなく、書き分けようとしたか。これなら「無意識に作ったものを後から分類しているだけ」という批判に耐える。

そして「その場で本人に返す」は人手ではできない。教師は32名の作問を即時に構造判定できない。**ai_judge がここを担うことが、システムの存在理由**になる。

## 3. 学習者モデルの再設計

産出×同定の2×2をやめ、**意識の状態**で立て直す。9/1のデータから実際に分布が出る。

| 状態 | 定義 | 9/1実測 | 支援 |
|---|---|---|---|
| **S0** 産出破綻 | 場面と問いが噛み合わない | p.11, p.18, p.32 等 | 成立性のフィードバック。構造以前 |
| **S1** 単一構造固定 | 1構造のみ。同型反復 | **15名(47%)** | 別構造の存在を名指す |
| **S2** 複数産出・無自覚 | 結果的に複数だが意図なし | 15名(47%)の多く | 自分の産出を構造として捉え直させる |
| **S3** 意図的作り分け | 構造を選んで作る | **1名(p.28)** | 未到達構造へ挑戦させる |

S3が目標状態で、現状ほぼ空。**S1→S2→S3への移行を促すのがシステムの機能要件**になる。

重要なのは、S2は紙の産出物からは S3 と区別できないが、**システムでは区別できる**という点だ。「次は別の型で作ってみよう」と促した直後に別構造を出せればS3寄り、出せなければS2。介入と測定が同じ操作で成立する。

## 4. システムのどこに研究の仕組みがあるか

これで宮寺先生の三点目に答えられる。汎用AIに「作問を手伝って」と投げても得られないものを列挙する。

| 機能 | 何が研究由来か |
|---|---|
| ai_judge 第2層 | 除数が場面で何を指すかで3構造を判別。三量命題モデル由来の判別規則 |
| **構造の即時フィードバック** | 産出直後に「これは等分除だね」と返す。**無自覚な産出を自覚に転じる中核機構** |
| 信号機UI | 到達構造数の可視化。**未到達構造の存在を本人に示す**＝意図的産出への誘導 |
| 停滞検出 | 「既出構造の再出現」＝同型反復の検出。9/1の実データから定義 |
| 段階的ヒント | 未到達構造を名指すが場面は完成させない。意図的産出の機会を奪わない |

**中核は2行目**だ。判定結果を本人に返すこと。これがなければ、システムは9/1の紙の課題と何も変わらない。逆にこれがあるから、「後から分類しているだけ」ではなくなる。

信号機UIも、単なる進捗表示ではなく**未到達の空白を見せる装置**として位置づけ直せる。3つのうち2つ点いていれば、残り1つの存在が本人に見える。

## 5. 課題の出し方を変える必要がある

ここが実装上の帰結だ。「24÷4になる問題をたくさん作ろう」のままでは、S1の児童は同型反復を続ける。段階を入れる。

- **第1段階**：自由に作る（＝事前測定を兼ねる。S0〜S3の判別）
- **第2段階**：構造フィードバックを受ける（「今作ったのは全部同じ型だよ」）
- **第3段階**：未到達構造への挑戦（意図的産出。ここでS2/S3が分かれる）

第1段階のログがそのまま事前データになるので、紙の事前テストは不要になる。**測定と支援が同じ判定機構を共有する**——これが宮寺先生の①への答えだ。

## 6. 事前事後テストと評価指標

主要指標を差し替える。

- **主要**：意図的産出の成否（「別の型で作ろう」と促されて別構造を出せたか）
- **副次**：到達構造数、構造別到達、成立率、同型反復率

到達構造数は残すが、**単独では構造的理解の指標にならない**と論文に明記する。倍が既習で高く出ても、主要指標は影響を受けにくい。これで前回懸念した天井効果の問題も、副次的なものになる。
