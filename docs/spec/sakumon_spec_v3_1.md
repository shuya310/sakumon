## 0. 改修の背景（9/17 模擬実践 #60 で見えたこと）

1. **強度0の対話が7ターン空回り**（17:58〜18:05）。強度0の talk は「自分の問題文の4のところを読んでみよう」以外ほぼ何も許されておらず、LLM は言い方の変奏（声に出して／心の中で）を生むしかなかった。対話ターンでは stuck が動かず、「違う数ってなんですか？」は help=false と設計していたため、昇格の契機が無かった。
2. 児童が自発的に「チームの人数」と役割を答えても強度0では受け取れず、help で強度1に上がった瞬間に ROLE_ASK「4は 何を あらわして いるかな？」を出して**3回答えたことをもう一度聞いた**。
3. 弱ターン2「4を 何の 数に して みたい？」に「わかりません」→ 仕様どおり無応答 → 同じ本文の再送で「おくったよ」が漏れた。
4. 画面上部「今 目指して いるのは『何倍』を 求める 問題」が構造名を漏らし、「倍の問題を作るの？？」を誘発した。
5. 初回称賛「4が ちがう 数を 表す 問題は 作れるかな？」は初見で意味が取れず（直後「違う数ってなんですか？」）、児童は題材だけ変えた（おにぎり→クラス→飴）。
6. 強度0の talk が「何人かで分けるお話に書きかえて」と行き先を指定していた（ガードが捕まえていない）。

根本には、支援が「遷移」（等分除↔包含除／分ける→倍／倍→分ける）を単位にしておらず、どこにいても同じ言葉を出していたことがある。

## 1. 全体像（置き換え）：4段階＝「どこまで示すか」

気づきは「自分の問題は同じだった（**現在地**）」と「除数を別の使い方にすれば変わる（**行き先**）」の2段で起きる。段階は、システムがどこまで示すかで決まる。

| 強度 | 示すもの | 決めるのは | 児童に出るもの |
|---|---|---|---|
| 0 なし | 何も示さない（促し） | 児童 | 称賛＋児童自身の除数の句の引用＋「4が ちがう ものの 数に なる お話は 作れるかな？」 |
| 1 弱 | **現在地**（これまでの問題は同じだった） | 児童（宣言） | 対比「『4人に 分けます』も『4人で 分けます』も、4は 同じ ことを 表して いるね。」＋「じゃあ 次は、4を どんな ふうに 使った お話に する？」 |
| 2 中 | **行き先**（除数をどう使うか） | システム | 「4を、分ける 人の 数に して みよう。おにぎりの お話は そのままで いいよ。」 |
| 3 強 | 行き先の**場面文** | システム＋場面固定 | 「「おにぎりが 24こ あります。4人で 同じ 数ずつ 分けます。」つづきの 問いを 書いて みよう。」 |

- 「なし・弱＝行き先を示さずに児童が見つけるか試す」「中・強＝行き先を示す」。弱にも気づきの支援（現在地の対比）は入る。
- 目標を決める主体が児童（弱の宣言）→ システム（中・強）へ移る点、随伴性（失敗ごとに1段）は v3 と同じ。指標（到達構造数・予告一致率 児童／システム・表層変換率）も同じ。
- Wood, Bruner & Ross (1976) の足場かけ機能で言えば、遷移表は "marking critical features"（着目点の明示）を段階ごとに定めたもの。理論の枠は変えず、抜けていた機能を埋める。

**弱の問い「4を どんな ふうに 使った お話に する？」は気づかせる問いではなく、宣言させる問い**（予告一致率（児童）＝意図性A の測定点）。気づきは直前の対比の文と、作問の成立で起きる。問いに学習効果は期待しない。答えられない（わかりません）こと自体が測定値。

## 2. 遷移

到達構造の集合と直前の成立作問から一意に決まる。

| 遷移 | 児童が気づくべきこと | 4の役割の変化 |
|---|---|---|
| A：等分除 ↔ 包含除 | 「4人で分ける」と「4こずつ分ける」は分け方がちがう | 人数 ↔ 1人分の数 |
| B：等分除・包含除 → 倍 | 分ける話ではなく、**くらべる**話。24は分けられない。4はもう一つの量 | 分ける相手 → 比べる相手の量 |
| C：倍 → 等分除・包含除（稀） | くらべる話から分ける話へ | 逆 |

- 弱の文言は到達集合で変形（`ai_dialogue.weak_variant`）。中・強は目標構造（未到達の先頭。`pick_unreached_structure` の固定順 tobun → hougan → bai）で決まる。
- 倍への遷移で弱の宣言が unknown になりやすいのは想定内（「倍への移行は児童の宣言では越えられない」という結果として扱う）。

## 3. 文言（置き換え）

`{dividend}` `{divisor}` `{unit}`（直前の成立作問の助数詞。無ければ「こ」）`{item}`（物。無ければ「◯ばんの お話」「もの」）`{phrase}`（成立作問の除数を含む句。`chat_logs.divisor_phrase`）。

### 3-3. 強度0（称賛）

判定と並行して `extract_divisor_phrase`（LLM → 除数を含む文 → なし）で除数の句を取り、`chat_logs.divisor_phrase` に残す。

| | 文言 |
|---|---|
| 新構造 | 新しい 問題が できたね！ この お話では、{divisor}は『{phrase}』の {divisor}だったね。<br>今度は、**{divisor}が ちがう ものの 数に なる** お話は 作れるかな？ |
| 同構造 | いいね、また 一つ できたね。この お話でも、{divisor}は『{phrase}』の {divisor}だね。<br>今度は、**{divisor}が ちがう ものの 数に なる** お話も 作れそうかな？ |
| 句なし | 引用の文を落とす |

### 3-4. 弱（1ターン）＝現在地の対比＋宣言

| 変形（到達集合） | 文言 |
|---|---|
| same：分ける系の中でのくり返し（倍だけ2問以上も） | {no1}ばんの『{phrase1}』も {no2}ばんの『{phrase2}』も、{divisor}は 同じ ことを 表して いるね。<br>じゃあ 次は、{divisor}を どんな ふうに 使った お話に する？ |
| same・句なし | {no1}ばんの お話も {no2}ばんの お話も、{divisor}は 同じ ことを 表して いるね。<br>（同上） |
| wakeru：等分除・包含除を両方到達 | これまでの お話は、どれも {dividend}{unit}を 分ける お話だね。<br>じゃあ 次は、{dividend}{unit}を 分けない お話に するなら、{divisor}を どんな ふうに 使った お話に する？ |
| kuraberu：倍だけ（2問以上） | これまでの お話は、どれも {dividend}{unit}と {divisor}{unit}を くらべる お話だね。<br>じゃあ 次は、くらべない お話に するなら、{divisor}を どんな ふうに 使った お話に する？ |
| one：成立作問が1問（help / talk で上がった） | {divisor}が『{phrase}』の {divisor}じゃ ない お話に するなら、{divisor}を どんな ふうに 使った お話に する？ |
| one・句なし | {no}ばんの お話とは {divisor}の 使い方が ちがう お話に するなら、（同上） |

「同じ構造の直近2問」は、最新の成立作問と同じ構造の直前の1問。

**答えの扱い（1回で閉じる。`awaiting` は必ず解除。宙に上げる）**

| 答え | 処理 | 返す定型 |
|---|---|---|
| 構造に分類できた（「4人で分ける」「4こずつ」「4こと くらべる」「人数」） | `declared`＝その構造・`declared_by=child`・`declared_text`＝児童の言葉 | じゃあ、その お話を 作って みよう。 |
| すでに到達済みの構造を宣言（誤答） | 上と同じ。**訂正しない**（児童の意図として記録。そのまま作れば stuck、違うものを作れば miss で段階が進む） | 同上 |
| わからない・題材だけ・質問で返した・その他（unknown） | 立てない | わからなくても だいじょうぶ。じゃあ、{divisor}を ちがう 使い方に した お話を 作って みよう。 |
| 完全な問題文（`looks_like_problem`） | 通常の作問処理（宣言待ちは打ち切り） | — |

- 分類は `ai_classify.classify_declaration`（式を渡す。「わる数をどう使うと書いているか」で tobun / hougan / bai / unknown）。
- 宣言の答えの中身を追う対話には入らない。宣言後の「どういうこと？」は通常の talk（help に分類されれば中へ）。
- 直前の AI が答えを待っている（`awaiting`）ときは、同じ本文でも答えとして扱い、再送にしない（「わかりません」→ 弱の問い →「わかりません」）。
- **旧 v3 の弱ターン1（役割の宣言：ROLE_ASK・`classify_role`・訂正・`role_answer` / `role_corrected`・`awaiting=role`）は廃止。** 列は残すが書き込まない。役割の自覚は弱の宣言に統合した（構造の識別はフェーズ1・3の選択でも測る）。

### 3-5. 中（行き先の指定＋題材固定）

| 目標 | 文言 |
|---|---|
| tobun | {divisor}を、分ける 人の 数に して みよう。{item}の お話は そのままで いいよ。 |
| hougan | {divisor}を、1人が もらう 数に して みよう。{item}の お話は そのままで いいよ。 |
| bai | {dividend}{unit}と {divisor}{unit}を くらべて、何倍かを 求める お話に して みよう。{item}の お話は そのままで いいよ。 |

### 3-6. 強（場面文提示）

| 目標 | 文言 |
|---|---|
| tobun | 「{item}が {dividend}{unit} あります。{divisor}人で 同じ 数ずつ 分けます。」<br>つづきの 問いを 書いて みよう。 |
| hougan | 「{item}が {dividend}{unit} あります。1人に {divisor}{unit}ずつ 分けます。」<br>つづきの 問いを 書いて みよう。 |
| bai | 「{friend_name}さんは {item}を {dividend}{unit}、{friend_name_alt}は {divisor}{unit} もって います。」<br>つづきの 問いを、「何倍」を 使って 書いて みよう。 |

### 3-8. 画面上部の目標表示（置き換え）

「つぎは「…」」。構造のラベル（1つ分の 大きさ／いくつ分／何倍）は出さない。

| 目標を決めたのが | 表示 |
|---|---|
| 児童（宣言） | 児童の言葉そのまま（`sessions.declared_text`） |
| システム | 行き先の言葉：tobun「{divisor}を 分ける 人の 数に した お話」／hougan「{divisor}を 1人が もらう 数に した お話」／bai「{dividend}{unit}と {divisor}{unit}を くらべる お話」 |

### 3-9. 同一本文の再送

成立作問と同じ本文（直前でなくても。空白の違いは無視）→ 判定も一覧への追加もせず「その お話は もう {ref_no}ばんに あるよ。ちがう お話を 作って みよう。」（`input_type=resend`）。

## 4. 強度の遷移（2-3 への追加）

- **0→1 に `talk` を追加**：強度0で、作問（sakumon）のあと対話（taiwa）だけが **3 ターン**続いたとき（`main.TALK_STALL_TURNS`。再送・宣言は数えない）。`strength_trigger="talk"`。help とは分けて記録し、支援要求の指標を濁さない。1 以上では talk では上げない。
- help / talk で 0→1 に上がったターンは、talk の文言（強度0）の後ろに弱の文言を連結し、`awaiting=declaration` で宣言を待つ（成立作問が無ければ連結しない）。

## 5. talk の境界（4-2・4-3 への変更）

| 強度 | 追加で許可 | 追加で禁止 |
|---|---|---|
| 0 | — | 子どもの問題を「分ける お話／くらべる お話」と分類する言い方（`banned_classify`）。行き先の指定（`role_spec`：何人で分け／人数にし／ずつにし／分ける 人の 数／もらう 数に／くらべる 相手／くらべて 等） |
| 1 | 現在地を示す（子ども自身の除数の句を並べて「同じ」と言い切る。「どれも 24こを 分ける お話だね」）。「{divisor}を どんな ふうに 使った お話に する？」と聞く | 行き先の指定（`role_spec`） |
| 2・3 | 行き先を言う（中・強の文言に合わせる） | — |

子どもが「ちがう」と主張したら、強度1以上では子ども自身の句を2つ並べて「どちらも 同じ ことを 表して いるね」と言い切る（共感のために肯定しない）。

## 7. 受け入れ条件（`backend/tests/test_flow.py`）

- 同構造3問目で弱：同じ構造の直近2問の除数の句を引用した対比＋宣言の問い。`awaiting=declaration`。再入場で復元
